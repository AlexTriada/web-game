# Task Force: Sierra

Браузерный тактический 3D-шутер от первого лица в эстетике ранних военных симуляторов 1990-х. Игрок проходит горный сектор, обнаруживает патрули, зачищает блокпост и захватывает радиореле.

## Запуск

Игра использует локальный HTTP-сервер, потому что браузер должен загружать GLB-модель персонажа.

```powershell
.\start-game.ps1
```

Затем откройте [http://localhost:8080](http://localhost:8080).

## Управление

| Клавиша | Действие |
| --- | --- |
| `W` `A` `S` `D` | Движение, независимо от раскладки клавиатуры |
| Мышь | Осмотр |
| ЛКМ | Огонь |
| `R` | Перезарядка |
| `C` | Пригнуться |
| `Esc` | Пауза |

## Возможности

- WebGL-ландшафт, лес, блокпост и радиовышка;
- first-person управление и стрельба по лучу;
- здоровье, броня, боезапас и перезарядка;
- миникарта с контактами, пауза и цель миссии;
- процедурные звуки оружия, попаданий, шагов и фоновая музыка;
- CC0-модель бойца в формате GLB.

## Технологии

Проект — статический сайт на HTML, CSS и JavaScript. Рендеринг построен на Three.js; GLB загружается через GLTFLoader.
